CapabilityStatement: Tjänstekatalogen: sök-API (externt) (Experimentell)

Officiell URL: https://fhir.inera.se/ig/tjanstekatalog/CapabilityStatement/tk-search-api Version: 0.1.0
Draft per 2026-09-08 Beräkningsbart namn: TKSearchAPICapabilityStatement

Beskriver de FHIR REST-förmågor som tjänstekatalogens sök-API exponerar externt, via gateway, för sökande konsumenter: läsning och sökning av organisationer och tekniska ändpunkter, inklusive sökning av ändpunkter per organisation (se SearchParameter: listed-by). Detta CapabilityStatement innehåller medvetet inga skrivinteraktioner (create/update) — dessa finns endast i administrativt API, som inte är externt exponerat. Se säkerhet och behörighet i security.html.
