Extension: API-instansens giltighetsperiod

Officiell URL: https://fhir.inera.se/ig/tjanstekatalog/StructureDefinition/tk-api-instance-period Version: 0.1.0
Draft per 2026-10-26 Beräkningsbart namn: TKAPIInstancePeriod

API-instansens (TKAPIInstance) egen giltighetsperiod, oberoende av den ändpunkt som tillgängliggör den (API.giltigFrom/giltigTom i informationsunderlaget).

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: CapabilityStatement

Usage info

Användningar:

  • Använd denna Extension: Tjänstekatalogen API-instans
  • Exempel för denna Extension: CapabilityStatement/TKAPIInstanceExample

Du kan också kontrollera användningar i FHIR IG-statistiken
