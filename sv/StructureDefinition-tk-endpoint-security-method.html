Extension: Säkerhetsmetod

Officiell URL: https://fhir.inera.se/ig/tjanstekatalog/StructureDefinition/tk-endpoint-security-method Version: 0.1.0
Draft per 2026-09-08 Beräkningsbart namn: TKEndpointSecurityMethod

Anger vilken säkerhetsmetod som skyddar åtkomst till ändpunkten (Ändpunkt.säkerhetsmetod i informationsunderlaget). Basresursen Endpoint saknar ett eget element för detta i R5.

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: Endpoint

Usage info

Användningar:

  • Använd denna Extension: Tjänstekatalogen Endpoint
  • Exempel för denna Extension: Exempelregionens patientinformations-API

Du kan också kontrollera användningar i FHIR IG-statistiken
