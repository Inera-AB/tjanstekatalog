Extension: Stödd specifikation (payload profile)

Officiell URL: https://fhir.inera.se/ig/tjanstekatalog/StructureDefinition/tk-endpoint-payload-profile Version: 0.1.0
Draft per 2026-09-08 Beräkningsbart namn: TKEndpointPayloadProfile

Kanonisk URL för en interoperabilitetsspecifikation (t.ex. en FHIR IG eller profil) som denna nyttolast/API stödjer. Motsvarar det kommande elementet Endpoint.payload.profile. Kan upprepas om nyttolasten stödjer flera specifikationer eller versioner.

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: Endpoint.payload

Usage info

Användningar:

  • Använd denna Extension: Tjänstekatalogen Endpoint
  • Exempel för denna Extension: Exempelregionens patientinformations-API

Du kan också kontrollera användningar i FHIR IG-statistiken
